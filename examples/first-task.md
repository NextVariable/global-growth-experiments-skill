# 增长实验执行与复盘：一次完整任务

以下为合成材料的工作示例，输入与输出节选经过编辑整理，不是真实客户结果。

## 输入

```text
使用 $global-growth-experiments。
我们对引导页做了按公司 ID 稳定随机的 A/B，计划 50/50，14 天、每组 100 家。完整走满 7 天观察窗的各 60 家，旧版成功导入 24 家、新版 33 家；其余各 40 家尚未成熟。正式实验前约定新版出现 3 家及以上错误跨客户展示数据就立即停，现已确认新版 3 家、旧版 0 家。老板说新版提升 15%，可以全量；同事说安全指标 p>0.05 就不必停。请复盘数字与决定，给今天能交给负责人执行的动作、下一轮设计，以及低流量时如何学习。不能声称你已切换线上开关。可用随包脚本计算，但不要求临时安装服务。
```

## 输出节选

成熟样本从 24/60 到 33/60：40%→55%，增加 15 个百分点，相对增加 37.5%。预设安全停止线已触发，应停止新版继续暴露。

不把尚未成熟的各 40 家当失败，也不用 p>0.05 证明安全；低流量时用真实任务观察排除障碍。

## 接下来怎么用

检查建议中的条件与你的实际产品是否一致，再补真实链接、责任人和授权。一次性任务直接使用正文即可；持续项目保留输入、来源、产物版本及下一步。方案和草稿不表示已执行，演示结果不证明真实业务收益。
