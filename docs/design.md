# 职责和取舍

本 Skill 解决增长动作的优先级、验证和结果解释。上游输入是产品目标、现实限制、已存在的内容/渠道/客户动作和数据；下游交付是可执行的试验、已核实的操作状态、可信范围内的结果以及明确的下一步。

第一部分决定市场与客户，第二部分制作表达和内容，第三部分组织发布与获客，第四部分推动购买和持续使用，第五部分用共同问题把执行与学习连起来。第五部分不成为调度所有工作的总控，也不强制其他 Skill 安装；用户可以只分析一场已完成试验。

入口负责按任务选择资料和完成条件。四份资料分别处理设计、测量、执行和复盘，模板只在保存或交接时使用。唯一运行时脚本是可单独运行的二元计数计算器；它不调用网络、不读业务文件、不改账户、不替代统计判断。

通过既有客户端工具取数和执行。明确授权内可实施动作并回读；没有工具或权限就输出具体阻塞及待执行包。不中转到自建 Agent 服务，不需要专有平台、付费账户或固定账本。

方法文件优先解决常见判断错误：低流量硬做 A/B、按发布时间归因、不同成熟窗口混算、重试导致重复执行、只看主指标忽略成本与退款。自动检查保护格式和算数；业务输出用独立模型试用和人工语义审阅，二者不互相替代。
